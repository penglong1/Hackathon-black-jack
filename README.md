# Grid Armor 坦克大战

一个无需安装依赖、可直接部署到 GitHub Pages 的 2D 坦克防守小游戏。

## 游戏玩法

- 战场固定为 20×30 网格。
- 方向键控制我方坦克，每次移动一格。
- 按 `X` 键发射炮弹。
- 敌方坦克从左上方入口出现，会绕行移动并以我方基地为主要目标，玩家需要主动拦截。
- 敌我炮弹在同一格相撞时会互相抵消。
- 击毁木质障碍物后，可能获得保护罩、镭射炮或地雷。
- 保护罩可以抵挡 3 次攻击。
- 镭射炮可以清除射线方向上的所有敌人。
- 踩到地雷会损失 1 点生命值。
- 战场每 30 秒随机投放一个道具，道具 10 秒内未被拾取会自动消失。
- 我方坦克或基地被摧毁后，游戏失败，可以点击重新开始。

## 操作方式

### 键盘

| 按键 | 操作 |
| --- | --- |
| ↑ ↓ ← → | 移动坦克 |
| `X` | 攻击 |

### 移动端

使用页面中的方向按钮移动，点击黄色圆形按钮攻击。

## 本地运行

在项目目录执行：

```bash
python3 -m http.server 4173
```

然后打开：

```text
http://localhost:4173
```
